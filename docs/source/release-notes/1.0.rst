***********
Version 1.0
***********

**Date:** 20 May 2025

Whats new?
----------

Symmetry analysis of Bravais lattices and all that was connected to it is removed. 
Please use |wulfric|_ instead.

Most of the things related with spin Hamiltonian and magnons has been removed. Please use|
|magnopy|_ instead.

Functions and classes remain in the package, but they print a message with the hint on
which package to use and where to go for the specific functionality, when possible.
